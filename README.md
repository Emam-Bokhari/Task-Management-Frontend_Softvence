# 📋 Task Management Application - Frontend

A beautifully designed and highly responsive **Task Management Application** built with modern frontend technologies. This project helps users efficiently manage their daily tasks with a clean UI, real-time interactivity, and better user experience.

---

## 🚀 Live Demo

🔗 [Click here to view the live site](https://task-management-frontend-softvence.vercel.app)

---

## 🖥️ Tech Stack

- ⚡ **Next.js 14** – React framework for SSR, SSG & Routing
- 🟦 **TypeScript** – Type-safe development
- 💨 **Tailwind CSS** – Utility-first CSS framework
- 🎨 **ShadCN UI** – Accessible, composable UI components
- 📦 **Zod / React Hook Form** – For type-safe form validation (if used)

## ⚙️ Getting Started

🔧 Installation

```bash
# Clone the repo
git clone https://github.com/Emam-Bokhari/Task-Management-Frontend_Softvence.git

# Navigate into the project directory
cd Task-Management-Frontend_Softvence

# Install dependencies
npm install

# Start the development server
npm run dev
```

🌐 Environment Variables

Create a .env.local file at the root:

```bash
NEXT_PUBLIC_API_URL=https://task-management-server-softvence-paic.vercel.app/
```
