## ⚙️ Getting Started

🔧 Installation

```bash
# Clone the repo
git clone https://github.com/Emam-Bokhari/Task-Management-Frontend_Softvence.git

# Navigate into the project directory
cd Task-Management-Frontend_Softvence

# Install dependencies
npm install

# Start the development server
npm run dev
```

🌐 Environment Variables

Create a .env.local file at the root:

```bash
NEXT_PUBLIC_API_URL=https://task-management-server-softvence-paic.vercel.app/
```
